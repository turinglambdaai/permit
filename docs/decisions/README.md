# Architecture decisions

Use a short architecture decision record (ADR) when a change affects protocol semantics, public API boundaries, cryptographic trust, compatibility, or the division between Permit and Commerce or another management service.

Copy [template.md](template.md), assign the next four-digit number, and keep the record with the code it governs. An accepted ADR explains context and trade-offs; the normative protocol specification still controls wire behavior.

Small implementation choices and ordinary bug fixes do not need an ADR.
